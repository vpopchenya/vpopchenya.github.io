# vpopchenya.github.io

Личный сайт Вадима Попченя, разработчика сайтов: услуги и цены, как проходит работа, обо мне и форма заявки. Две языковые версии: русская (`/`) и английская (`/en/`).

Сайт статический: HTML, CSS и немного JavaScript, без сборки и без внешних шрифтов (используются системные). Размещён на GitHub Pages.

Подробное описание того, как сайт устроен и почему (дизайн, анимации, адаптив, SEO, безопасность): [CLAUDE.md](CLAUDE.md).

## Структура

```
index.html            русская версия
en/index.html         английская версия
privacy/              политика конфиденциальности (RU), en/privacy/ (EN)
404.html              страница «не найдено»
css/style.css         все стили
js/main.js            анимации и форма заявки
img/                  картинки для превью в соцсетях (1200x630)
favicon.svg           иконка сайта
robots.txt, sitemap.xml   для поисковиков
```

## Что нужно заменить перед запуском

В коде эти места помечены комментариями `ЗАГЛУШКА` / `PLACEHOLDER`.

1. **Email в политике конфиденциальности**: на страницах сайта контакты уже настоящие, а в политике пока неактивная надпись вместо адреса.
2. **Цены и состав тарифов** в блоке «Услуги и цены».
3. **Карточки «Мои сайты»**: сейчас это неактивные блоки «Место для проекта». Замените на `<a class="card" href="...">` с настоящей работой.
4. **Картинки для соцсетей** `img/og-ru.png` и `img/og-en.png`: загрузите в папку `img/`.
5. **Форма заявки**: зарегистрируйтесь на [web3forms.com](https://web3forms.com), получите ключ и вставьте его в `data-key=""` у `<form id="order-form">` в обоих `index.html`. Пока ключа нет, форма ничего не отправляет. Перед подключением проверьте требования 152-ФЗ (см. CLAUDE.md).
6. **Политика конфиденциальности** написана как черновик. Проверьте её (желательно с юристом) и обновите дату.

## Тесты

Автотесты pytest + Playwright лежат в `tests/`. Запуск из папки сайта: `python -m pytest tests` (сервер тесты поднимают сами). Что проверяет каждый файл, написано в CLAUDE.md.

## Безопасность

Политика `Content-Security-Policy` задана тегом `<meta>` в каждой странице: загружаются только свои файлы, а запросы наружу разрешены только к `api.web3forms.com`. Если вы меняете маленький встроенный скрипт в `<head>`, пересчитайте его хеш `sha256` в этой политике. Если добавляете новый внешний сервис, добавьте его адрес в политику.

## После публикации

1. Откройте GitHub: Settings, Pages, источник `main` / корень.
2. Добавьте сайт в Google Search Console и в Яндекс Вебмастер, отправьте `sitemap.xml`.
3. Укажите ссылку на сайт в профиле GitHub, Telegram и на площадках, где ищете клиентов.
