Кто обрабатывает данные

Данные обрабатывает Вадим Попченя (физическое лицо), владелец сайта vpopchenya.github.io. Связаться по вопросам данных можно по адресу name@example.com.

Какие данные и зачем

Когда вы отправляете заявку, сайт получает имя, контакт для связи (Telegram или email), выбранный тип сайта и текст сообщения. Эти данные нужны, чтобы ответить на заявку и обсудить заказ. Для других целей я их не использую.

Основание

Данные обрабатываются с вашего согласия. Согласие вы даёте, отметив галочку в форме перед отправкой.

Кому данные передаются

Заявку принимает сервис Web3Forms (web3forms.com): он пересылает её на мою почту. Сайт размещён на GitHub Pages, который может хранить технические журналы посещений, например IP-адрес. Серверы этих сервисов могут находиться за пределами России. Больше никому данные не передаются и не продаются.

Сколько хранятся данные

Заявки хранятся в моей почте не дольше, чем нужно для ответа и договорённостей. Если вы не стали клиентом, я удаляю заявку не позднее чем через 12 месяцев.

Cookie и аналитика

Сайт не использует cookie, счётчики и сервисы аналитики.

Ваши права

Вы можете в любой момент отозвать согласие, узнать, какие ваши данные у меня есть, или попросить их удалить. Для этого напишите на name@example.com.
